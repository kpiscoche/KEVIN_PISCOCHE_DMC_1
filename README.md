# KEVIN_PISCOCHE_DMC_1

Este proyecto consiste en una aplicación interactiva desarrollada con Streamlit, enfocada en la gestión financiera personal.

Curso: Python for Analytics(2026) por Kevin Piscoche

A lo largo del desarrollo se integran los siguientes fundamentos:
- Variables y estructuras de control
- Listas y diccionarios
- Funciones y enfoque funcional
- Programación Orientada a Objetos (POO)

🎯 Propósito del Proyecto

El objetivo principal es demostrar el dominio de los conceptos básicos de Python mediante la construcción de una aplicación funcional con enfoque financiero, combinando:

- Manipulación de datos
- Lógica condicional
- Programación funcional
- Diseño orientado a objetos

🧩 Funcionalidades Principales

La aplicación permite al usuario:

- Registrar presupuestos mensuales
- Comparar gastos reales frente a lo planificado
- Calcular retornos de inversión
- Gestionar actividades financieras dinámicamente
- Evaluar el estado financiero en tiempo real
🔍 Desarrollo por Secciones
1️⃣ Variables y Condicionales

Validación del presupuesto mensual

Comparación entre gasto estimado y real

Generación de alertas dinámicas

Indicadores visuales del estado financiero

Procesos básicos de limpieza de datos

2️⃣ Listas y Diccionarios

- Registro estructurado de actividades
- Uso de estructuras tipo lista y diccionario
- Visualización en formato tabular
- Cálculo automático de variaciones
- Resumen consolidado de métricas

3️⃣ Funciones y Programación Funcional

- Cálculo del retorno de inversión (ROI)
- Implementación de map() y funciones lambda
- Uso de apply() en Pandas
- Eliminación dinámica de registros
- Cálculo agregado de inversión, retorno y ganancia

4️⃣ Programación Orientada a Objetos

- Definición de la clase Actividad
- Atributos: nombre, tipo, presupuesto y gasto real
- Método esta_en_presupuesto()
- Método mostrar_info()
- Creación dinámica de objetos desde formulario
- Evaluación automática del cumplimiento financiero
